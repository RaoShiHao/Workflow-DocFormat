# Format adjustment requirements

## Section

### Cover section

Use for the title page only. It holds the cover title, logo, and cover information table without a visible header.
Set top margin to 3.5cm, left margin to 3cm, right margin to 3cm, page number format to upper Roman; Enable different first page; Footer: Set alignment to center, font size to 9pt, text color to #B0B0B0.

### Contents section

Use for the table of contents pages in the front matter. It supports a clean navigational page before the report body begins.
Set top margin to 2.5cm, left margin to 2.5cm, page number format to upper Roman; Header: text is "Contents"; Set text color to #A0A0A0; Footer: Set field to page, alignment to center, font size to 9pt, text color to #808080.

### Opening message section

Use for the chairman letter or opening message section. It supports narrative text with an accompanying portrait image.
Set left margin to 3cm, page number format to upper Roman; Enable different first page; Header: text is "Opening Message"; Set text color to #A0A0A0; Footer: Set field to page, alignment to center, font size to 9pt, text color to #808080.

### Group overview section

Use for the group overview chapter. It introduces corporate profile, strategy, footprint, and business model content.
Set top margin to 2.5cm, left margin to 3cm, page number format to Arabic numerals, section break type to next page; Header: text is "Rivermark Group Annual Report"; Set text color to #808080; Footer: Set field to page, alignment to center, font size to 9pt, text color to #808080.

### Segment review section

Use for recurring operating segment chapters. The same section style serves Industrial, Consumer, and Services reviews for consistency.
Set top margin to 2.5cm, left margin to 3cm, page number format to Arabic numerals, section break type to next page; Header: text is "Segment Review"; Set text color to #666666; Footer: Set field to page, alignment to center, font size to 9pt, text color to #808080.

### Governance section

Use for governance content covering board structure, leadership, and oversight. It supports roster tables, portraits, and organization diagrams.
Set left margin to 3cm, page number format to Arabic numerals, section break type to next page; Header: text is "Governance and Leadership"; Set text color to #666666; Footer: Set field to page, alignment to center, font size to 9pt, text color to #808080.

### Risk and sustainability section

Use for risk management, ESG, and safety reporting. It supports matrix-style tables, KPI tables, and trend charts in one chapter.
Set top margin to 2.5cm, left margin to 3cm, page number format to Arabic numerals, section break type to next page; Header: text is "Risk and Sustainability"; Set text color to #666666; Footer: Set field to page, alignment to center, font size to 9pt, text color to #808080.

### Financial statements section

Use for the primary consolidated statements chapter. It is the main home for statement tables and concise supporting commentary.
Set top margin to 2.5cm, left margin to 3.17cm, page number format to Arabic numerals, section break type to next page; Header: text is "Financial Statements"; Set text color to #666666; Footer: Set field to page, alignment to center, font size to 9pt, text color to #808080.

### Financial notes section

Use for simplified accounting note groups that follow the statements. It supports schedule tables and compact explanatory text.
Set top margin to 2.5cm, left margin to 3.17cm, page number format to Arabic numerals; Header: text is "Notes to the Financial Statements"; Set text color to #808080; Footer: Set field to page, alignment to center, font size to 9pt, text color to #808080.

## Heading paragraph

### Cover title

Use for the main report title on the cover page. It is reserved for the most prominent opening title only.
Set Latin font to Arial, East-Asian font to Heiti/SimHei, font size to 22pt, alignment to center, space after to 24pt.

### Heading 1

Use for all body chapter titles in the main report. It covers H1 chapter starts such as Group Overview, Governance, and the financial chapters.
Set font size to 18pt, space before to 24pt, space after to 12pt; Enable page break before.
Heading 1 may look like `Chapter 1 …`.

### Heading 2

Use for second-level body headings within each chapter. It groups major subtopics such as performance review, strategy, or statement sets.
Set outline level to 1, font size to 14pt, space before to 18pt, space after to 6pt.
Heading 2 may look like `Section 1 …`.

### Heading 3

Use for third-level body headings in nested topic blocks. It structures detailed discussion areas such as business mix, principal risks, or environmental data.
Set outline level to 2, font size to 12pt, space before to 12pt, space after to 6pt.
Heading 3 may look like `Subsection 1 …`.

### 标题 4

程序补入：正文标题层级（stylesheet 未声明）.
Set Latin font to Calibri, East-Asian font to Microsoft YaHei, font size to 10.5pt, alignment to left, space before to 6pt, space after to 3pt, outline level to 3.
标题 4 may look like `1.1 …`.

## Body paragraph

### Contents entry

Use for top-level entries in the contents page. It lists the major report chapters without entering the Word heading outline.
Set font size to 10.5pt, alignment to left, space before to 6pt, space after to 6pt.

### Opening narrative

Use for the chairman letter and for front-matter highlight prose after C1 merging. It carries compact introductory narrative before the main body.
Set font size to 12pt, alignment to justify, line spacing to 1.5x, space after to 12pt, first-line indent to 0.5in.

### Body text

Use for most narrative prose across body chapters and back-matter explanatory text after merging. It is the default running paragraph for business, governance, risk, and closing statements.
Set font size to 10.5pt, alignment to justify, line spacing to 1.5x, space after to 12pt, first-line indent to 0.5in.

### Summary paragraph

Use for short chapter-opening summaries and key takeaways inside the report body. It introduces a section before tables or charts without becoming a heading.
Set font size to 12pt, alignment to justify, line spacing to 1.15x, space after to 12pt.

### Statement lead

Use for lead lines that introduce a primary statement or a note schedule. It helps frame major financial tables before the reader reaches detailed rows.
Set font size to 10.5pt, alignment to left, space before to 12pt, space after to 6pt; Enable bold.

### Source note

Use for short basis, scope, and source notes under tables or figures. It provides concise supporting context without the density of a disclosure paragraph.
Set font size to 10.5pt, alignment to left, space before to 6pt, space after to 6pt.

### Caption

Figure/table captions.
Set Latin font to Cambria, East-Asian font to Song/SimSun, font size to 10.5pt, alignment to center, space before to 6pt, space after to 6pt.

## Table-cell paragraph

### Header cell

Use for text inside table header cells. It serves column headings and other shared header positions across all retained table types.
Set alignment to center; Enable bold.

### Data cell

Use for all non-header table cell text after C1 merging, including data, stubs, labels, and note rows. It creates a small shared in-cell text system for compact report tables.
Set alignment to left.

## Run

### Lead bold

Use for short bold lead-ins at the start of a sentence or paragraph. It highlights label-style openings such as metric names or thematic cues.
Enable bold.

### Superscript note mark

Use for note reference marks attached to text or numbers. It supports compact references in narrative, notes, and financial lead lines.
Enable superscript.

### Italic term

Use for defined terms, named measures, or report terminology that needs light semantic distinction. It provides subtler emphasis than bold text.
Enable italic.

## Table

### Cover information table

Use for the small cover-page facts table. It presents report details in a simple label-and-value arrangement without a full grid.
Table-level: inherit table defaults; label column: Set vertical align to center; value column: Set bottom border to single;4;auto, vertical align to center.

### Performance data table

Use for KPI, segment, sustainability, and other business performance tables across the report body. It is the default analytical table for period comparisons.
Table-level: ; Enable repeat header row; header row: Set top border to single;12;auto, bottom border to single;4;auto, vertical align to center; stub column: Set vertical align to center; Data cell: Set vertical align to center; table note: Set top border to single;12;auto, vertical align to top.

### Financial statement table

Use for the primary consolidated statements in the financial statements chapter. It is kept distinct to preserve the importance and readability of core statement layouts.
Table-level: ; Enable repeat header row; header row: Set bottom border to single;4;auto, vertical align to bottom; stub column: Set vertical align to bottom; Data cell: Set vertical align to bottom; table note: Set top border to single;4;auto, vertical align to top.

### Disclosure schedule table

Use for note schedules and fully gridded disclosures in the financial notes chapter. It handles denser data blocks than the standard performance table.
Table-level: Set border (all sides) to single;4;auto; Enable repeat header row; header row: Set border (all sides) to single;4;auto, vertical align to center, cell shading to #E7E6E6; stub column: Set border (all sides) to single;4;auto, vertical align to top; Data cell: Set border (all sides) to single;4;auto, vertical align to center; table note: Set border (all sides) to single;4;auto, vertical align to top.

## Image

### Cover logo

Use for the corporate logo or report emblem on the cover. It is reserved for branding on the opening page.
Set width to 6cm, height to 3cm.

### Performance chart

Use for bar, line, or pie charts showing KPIs, segment trends, financial movement, or ESG indicators. It is the main statistical chart style across the report.
Set width to 11cm, height to 7cm.

### Structure diagram

Use for organization or governance structure diagrams. It suits board committees, reporting structure, or corporate arrangement visuals.
Set width to 13cm, height to 9cm.

### Process diagram

Use for value-chain, operating-model, control-cycle, or mitigation-process visuals. It explains sequential or flow-based concepts in the report body.
Set width to 14cm, height to 7cm.

### Operations photo

Use for facility, team, or operating-scene photographs in segment and overview chapters. It adds visual context to business activity without acting as a portrait.
Set width to 12cm, height to 8cm.

### Portrait photo

Use for the chairman portrait in the opening message and executive or director portraits in governance sections. It is the dedicated people-photo style.
Set width to 8cm, height to 10cm.

### Footprint map

Use for maps showing operating regions, sites, or market presence. It is distinct from charts and diagrams because geographic reference drives its layout.
Set width to 14cm, height to 8cm.
